# Learnings（skill 自我學習紀錄）

這個檔案由 skill 在使用過程中**自動累積**：每當使用者修正一個決策或表達偏好，
就把它蒸餾成一條可重用的規則記在這裡。skill 每次啟動都會先讀這份檔案。

## 規則格式

```
### <短標題>（YYYY-MM-DD）
- **規則**：一句話，下次直接可執行
- **為什麼**：當時被修正的原因（一句話）
- **適用**：design / timing / audio / workflow
```

寫入原則：
- 記**通用規則**，不記單一影片的細節（具體秒數、專案文案不要進來）
- 與既有規則衝突時**更新舊條目**而不是並列，並改日期
- 已被納入 SKILL.md 正文的慣例不用重複記
