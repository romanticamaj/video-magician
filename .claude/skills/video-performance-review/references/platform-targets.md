# 平台事實與節奏門檻

⚠️ 本頁的平台數字是 **`[EXT]`：平台在某個時間點的官方／公開說法**，
不是成效保證，而且會隨產品改版變動。**查證日期：2026-07。**
引用超過三個月就要重新查，不要把它當永久真理寫進結論。

## 排序訊號（Meta）

Mosseri 公開確認的三大訊號：**watch time、sends per reach、likes per reach**。
留言不在前三，但**4 字以上的留言**是很強的次級訊號（高於儲存與按讚），
一詞留言權重趨近於零。詳見 `conversation-mechanics.md`。

## 平台差異

| | Facebook / IG Reels | Snap Spotlight |
|---|---|---|
| 排序依據 | watch time + sends | **完成率**（不是總觀看時間） |
| 長度甜區 | 15–30s 仍穩；2026 起較長內容對撐得住留存的帳號也吃香 | 10s–60s；新帳號 15–30s |
| 硬條件 | 前 3 秒流失可達 50% | **滿 30s 才能營利** |
| 留言環境 | 公開留言即時可見 | 公開留言需創作者核准，較不易形成留言區 |

### 編輯上的差別 `[B-heuristic]`

**Facebook / IG Reels**
- 需要鋪陳＋證據＋討論提示時，25–40s 是舒服的區間。
- 偏好「經驗、判斷、取捨」型問題——這些會長出回覆串。
- 燒錄字幕自己控（不要依賴平台自動字幕，時間與用詞都不受控）。
- 討論提示**不要只放在最後一秒**當交差用的片尾卡。

**Snap Spotlight**
- 只有在「同樣的證據能更早講完、且不損理解」時才做 15–28s 變體。
- 證據與可回答的選擇要更早出現；兌現之後的重複驗證砍得更兇。
- 適合的機制：個人反應、二選一裁決、影片回覆、remix、「換你試試」。
- 保留手機自製感，不要加平台通用的品牌裝飾。

**聲音與字幕（單一規則，適用全部平台）**
> 故事必須**靜音看得懂**；聲音只負責讓節奏與笑點更好。

## 節奏門檻（只用來定位要看的視窗，不是評分）

| 指標 | 參考帶 | 注意 |
|---|---|---|
| 總長 | 20–40s（本專案 brief） | 不要為了湊數字而砍 |
| 第一個可理解的命題 | ≤1.5s | 封面可以不靠人聲就完成 |
| 第一個證據／反應 | 3–5s | **口頭承諾不算證據** |
| 完整兌現 | 8–15s；更晚就要在 5s 前給一個小兌現 | 有些故事本來就多段兌現 |
| 保留段長度中位 | 2.5–4.5s | >6s 的段落要看、<0.7s 的密集區要看 |
| 字幕閱讀負荷 | 3.5–7 字/秒舒服；7–9 要看；>9 太快 | 短反應（「屁啦」）是合理例外 |
| 字幕空檔 | >0.6s 要看，>1.0s 預設可疑 | **絕不自動剪**；畫面可能自帶聲音或是笑點節拍 |
| 同時強化項 | 3 項以上要看 | 笑點本來就該疊，看了再判 |

## 循環性

- 判斷最後一個畫面／句子能不能順順接回開頭，有沒有「死掉的片尾」。
- 可調欄位：`outroFrames`、`outroFadeFrames`、`endCard`、封面長度。
- `[C]` **不要宣稱無縫循環會得到演算法偏好**。它只是一個創作上的連續性選擇。

## 匯出規格

`[A]` 1080×1920、H.264/AAC、30fps 直式適用於所有目標平台。
成品響度 -14 LUFS / TP ≤ -1.5 dBTP（見 video-magician 的 `audio-mixing.md`）。
